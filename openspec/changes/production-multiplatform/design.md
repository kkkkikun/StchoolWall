# 设计与迁移约束

1. FastAPI模块化单体连接PostgreSQL、Redis和私有对象存储；API和独立worker分别运行，首版不拆微服务。
2. 一个UserUUID对应多个LoginIdentity。微信provider包含AppID；绑定依赖两端已登录后的短时单次配对，不自动合并有内容身份。
3. Refresh只存随机凭证哈希，轮换历史保留到会话到期；旧凭证重放撤销会话。Web刷新放HttpOnly cookie，CSRF来源与随机值校验。
4. 学生证独立私有桶，HMAC独立密钥并有key version；不持久化真实姓名或原始学号。单独同意、同框码、人工核对、时效及物理删除是完整边界。
5. 媒体由服务端生成ID；公开读取以数据库批准状态为准。审核缺配置、异常和额度失败都保持待审。
6. 业务记录和Job同事务落库；worker skip-locked认领、租约防旧worker回写、状态/版本条件防机器覆盖人工。
7. 人工处置与审计同事务；申诉接受不自动跳过发布状态机。拉黑按认证访问者执行双向发现/互动限制。
8. 发布产物只构建一次，扫描后晋级；迁移独立单次执行。首次切换清理旧认证需维护窗口，后续采用兼容迁移。应用回滚不自动逆向迁移DB。
9. 代码门禁与真实门禁独立。没有压测、恢复或真机证据，不能宣称满足SLO或可上架。
