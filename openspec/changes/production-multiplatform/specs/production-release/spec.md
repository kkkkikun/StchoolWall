## ADDED Requirements

### Requirement: 统一身份与可撤销会话

系统 MUST 以同一用户UUID关联跨端登录身份，禁止按昵称或学号自动合并；access最长15分钟，refresh最长30天，轮换且仅存哈希，服务端可以立即撤销。

#### Scenario: 身份绑定与刷新重放
- **WHEN** 用户绑定另一端身份或已轮换刷新凭证再次出现
- **THEN** 绑定须经短时单次配对和新近认证；有内容或认证历史不自动合并；重放撤销相关会话和未使用配对码

### Requirement: 私有学生证人工核验

系统 MUST 停用教务密码认证，使用账号绑定的同框随机码和私有学生证人工核验；不持久保存原始学号或姓名。

#### Scenario: 核验与资料删除
- **WHEN** 学生提交证件或达到材料保留期限
- **THEN** 照片仅由授权审核员访问并审计；学校及独立HMAC指纹用于去重，结果7天、待审14天物理删除；注销安排立即清理，备份恢复后继续执行删除

### Requirement: 隔离媒体与可靠审核

系统 MUST 校验media_id所有者、用途、状态和大小，图片真实解码并去EXIF；业务和审核任务同事务提交，由独立worker处理。

#### Scenario: 审核故障与人工决定
- **WHEN** 供应商超时、缺少配置、worker重启或人工已作出新决定
- **THEN** 内容保持待审，任务支持租约接管和有限重试；旧worker不得覆盖人工决定，管理员可以审计后处理队列

### Requirement: 独立管理身份与社区治理

系统 MUST 使用独立管理员会话及生产MFA，敏感操作留审计；提供举报、申诉、拉黑和投稿开关。

#### Scenario: 管理或治理操作
- **WHEN** 管理员查看证件、审核、封禁、接受申诉或关闭投稿
- **THEN** 必须验证独立权限并审计；申诉接受不自动发布，冻结撤销用户会话，关闭投稿保留既有浏览能力

### Requirement: 生产发布证据与三端验收

系统 MUST 保留Web→小程序→Android发布顺序，CI测试与扫描通过后晋级同一不可变制品，数据库独立迁移；缺少实际验收证据禁止发布。

#### Scenario: 发布前审查
- **WHEN** 准备真实开放任一客户端
- **THEN** 必须取得主体准入、安全、容量、恢复及对应真机证据；100req/s30分钟、200req/s5分钟、8小时长稳、99.5%可用性、RPO≤1小时、RTO≤4小时均以实测验收；未修复高危依赖保持发布阻断
